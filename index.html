Важный принцип

Конфиденциальность

Сведения из обращения используются только для предварительной оценки вашей задачи. Доступ к ним получает ответственный специалист.

Работа ведётся в пределах действующего законодательства. Мы заранее сообщаем, какие действия возможны, какие данные потребуются и в каком виде будет передан результат.

  • Без передачи обращения посторонним
  • Без незаконных способов получения информации
  • С понятным планом до начала работы

Частые вопросы

Можно ли обратиться без звонка?+

Да. Опишите ситуацию в форме и выберите удобный письменный способ связи.

Сколько стоят услуги?+

Стоимость зависит от задачи, объёма проверки и сроков. Предварительный расчёт готовится после знакомства с ситуацией.

Как быстро начинается работа?+

После консультации, согласования плана и условий. Срок начала специалист сообщит в письменном ответе.

Какие сведения нужно предоставить?+

Для первого обращения достаточно кратко описать обстоятельства и ожидаемый результат. Остальные данные специалист запросит при необходимости.

Можно ли получить письменный отчёт?+

Формат результата согласуется заранее. Для ряда задач можно подготовить письменный отчёт с собранными сведениями.
